# Twin Torque website

Static HTML, CSS and JavaScript website for Twin Torque.

## Live site

https://twin-torque-site.onrender.com/

## Booking and enquiries

- Studio appointments: https://calendly.com/abhibhanoor/30min
- The current Calendly event is 30 minutes, uses the existing weekday availability in India Standard Time, and displays a studio label without exposing the address.
- The project enquiry form prepares a WhatsApp draft for visitors to review and send.

## Deployment

The site is hosted as a Render static site from the `main` branch. Its publish directory is the repository root; no package installation is required. `render.yaml` contains the corresponding static-site configuration.

The Bentley hero image supplied for the site is stored in `assets/bentley-cover.png`. Other vehicle photography is used for visual studies; replace it with Twin Torque's own completed-project photography as it becomes available.
