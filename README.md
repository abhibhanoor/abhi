# Twin Torque

Premium automotive protection, performance and personalisation.

This is a static HTML/CSS/JavaScript site. The Bentley cover image is stored at `assets/bentley-cover.png`.

## Deploy on Render

- Service type: Static Site
- Build command: `echo "Static HTML site"`
- Publish directory: `.`
- Render configuration: `render.yaml`

## Booking and enquiries

The studio consultation link opens Calendly. The project enquiry form prepares a WhatsApp message for the visitor to review and send to the studio.
